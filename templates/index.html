Under the Hood
Useful for documentation & viva

  1. Collect groundwater data and lab-measured parameters.
  2. Clean, preprocess and apply Box-Cox / Yeo-Johnson transforms.
  3. Train Random Forest models for drinking & irrigation classes.
  4. Save models, transformers and label encoders as pickle files.
  5. Flask app reads new inputs, repeats the same transforms.
  6. Predicted class + parameter insights are passed to Gemini.
  7. Gemini returns structured, human-readable recommendations.

Backend model: Random Forest classifier trained on:

  • pH, EC, TDS
  • Carbonate, Bicarbonate
  • Chloride, Sulfate
  • Fluoride, Nitrate
  • Sodium, Calcium, Magnesium
  • Total Hardness
  • Sodium Adsorption Ratio (SAR)
  • Residual Sodium Carbonate (RSC)

Targets are label-encoded quality classes (e.g. Suitable, Marginal, Unsuitable) that are decoded back into readable text on the result page.
