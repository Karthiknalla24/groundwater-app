#  Groundwater Quality Prediction System

##  Project Overview
This project is an AI-based web application that predicts groundwater quality using Machine Learning models. It helps analyze water suitability for drinking and irrigation purposes.

---

##  Features
- Predict groundwater quality using ML model
- User-friendly web interface
- Provides insights and recommendations
- Supports multiple water parameters
- Fast and accurate predictions

---

##  Tech Stack
- Python
- Flask
- Machine Learning (Random Forest)
- HTML, CSS, JavaScript

---

##  Project Structure
- `app.py` → Main application
- `ml/` → ML logic and prediction
- `Models/` → Trained model files
- `templates/` → HTML pages
- `static/` → CSS, JS, images

---

##  How to Run
```bash
pip install -r requirements.txt
python app.py
